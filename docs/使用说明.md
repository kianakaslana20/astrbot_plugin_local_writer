# 本地 AI 成人小说工作台（SillyTavern + KoboldCpp + Qwen2.5-7B-abliterated）

全部离线运行：不联网、不花钱、无内容审查。所有人物均为虚构成年人（20 岁以上）。

**已全部装好并实测通过**，你现在只需要双击一个 bat 就能开始写。

## 一、怎么开始（三步）

1. 双击 `E:\AI-NSFW-Writer\启动全部.bat`
   - 会弹出一个启动器窗口，然后自动开出**两个黑色窗口**：
     - `KoboldCpp 5001`：加载模型（4.36GB 进显卡，约 20–40 秒），出现 `listening on 5001` 就是好了；
     - `SillyTavern 8000`：写作界面服务。
   - **这两个窗口都要留着**，关掉就等于关掉服务。
   - 约 25 秒后浏览器会自动打开 <http://127.0.0.1:8000>。
2. 首次进入点掉 18+ 内容提示。
3. 左下角角色列表里点 **「夜阑」** → 直接在输入框里说「谁、在哪、要发生什么」，它就开始写正文。

API、端口、采样参数、角色卡都已经配好了，不用再手动设置。

### 双击没反应怎么办

先跑 `E:\AI-NSFW-Writer\scripts\check.bat`，它会逐项列出：文件在不在、5001/8000 通不通、模型 API 有没有响应、node 和显卡状态。看到哪一行是 `[MISS]` / `[DOWN]` 就是那里出了问题。

常见两种：

| 现象 | 原因 | 处理 |
|---|---|---|
| 双击后窗口一闪就没、什么都没起 | bat 行尾被改成了 Linux 的 LF（编辑器/网盘同步常见） | 用 `scripts\check.bat` 确认；重跑 `scripts\fix-bats.py` 可恢复（需要 Python） |
| 生成速度突然掉到 7 tok/s，GPU 却显示 100% | 全量 offload 挤爆 6G 显存，回退到系统内存了 | 按实测 `--gpulayers 26` 是甜点，脚本里已经是这个值；再慢就降到 22 |

想看每个服务的实时日志：直接双击 `scripts\1-start-koboldcpp.bat` 或 `scripts\2-start-sillytavern.bat` 单独启动，窗口里会打印全部输出。

## 三、怎么写才出好效果

「夜阑」这张卡的行为约定是：你给方向，它写正文，一次一段，不解释、不道歉、不淡出。

**开局可以直接这样说：**

```
林晚和程野，大学同学，毕业五年后在同学会重逢，喝多了，一起回酒店。
写电梯到进门这一段，尺度放开，写具体。
```

**要继续推进，就这样追加：**

```
继续。写到两个人进浴室，别跳，把身体反应和对话都写出来。
```

**想要更长的段落**：把右侧 Simple/Advanced 里的 **Response Length（Max Response Length）** 从 600 调到 900–1200（约 1300–1800 汉字）。

**几个实用技巧：**

- 每次只让它写一段，你接一句方向，比一次性要长文效果好得多（7B 模型上下文长了容易跑偏）。
- 卡里给了三个默认开头（雨夜留宿 / 年会酒店走廊 / 第三者），没想法时直接挑一个。
- 觉得它开始说教或跑题：点「重新生成」，或在输入框补一句「刚才那段作废，回到浴室场景，接着写」。
- 想让它记住人物设定：把人物小传写进聊天开头的 `[OOC]` 里，或直接贴进第一条消息。

## 五、硬件与性能（本机实测）

- GPU：RTX 3060 Laptop 6GB —— 模型 29/29 层全部进显存（4168 MiB）+ KV cache q8_0 245 MiB，**不 OOM**。
- 上下文 8192（KoboldCpp 实际分配 8448，含预留）。
- 生成速度实测约 **25–30 tokens/秒**（中文约 1 字/token，即每秒 25–30 字），400 tokens 约 15 秒。

**为什么是 26 层而不是 99**：6G 卡跑 Q4_K_M 的 7B，29 层全塞进显存会贴到天花板，Windows 把超出的部分丢回系统内存，速度从 23 tok/s 掉到 7 tok/s，GPU 却显示 100%。26 层留 650 MiB 余量，实测 23.4 tok/s。显存还紧就降到 22。

**想拉长上下文**（写长篇、要它记住前面几章）：

```

```

## 六、换模型 / 加模型

模型都是 GGUF 格式，扔进 `models\` 再改 bat 里的 `--model` 路径即可。

下载走镜像（HuggingFace 官方直连不通，hf-mirror 单线程限速，必须并发分段）：

```powershell
$py = 'C:\Users\Administrator\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe'
& $py 'E:\AI-NSFW-Writer\scripts\pdl.py' `
  'https://hf-mirror.com/<repo>/resolve/main/<file>.gguf' `
  'E:\AI-NSFW-Writer\models\<file>.gguf' 16 6
```

**6GB 显存可选的替代模型：**

- `mradermacher/Qwen3-8B-abliterated-GGUF`（Q4_K_M 约 4.7GB，中文更强，需关 thinking）
- `huihui-ai/Qwen2.5-7B-Instruct-abliterated` 的其它量化版
- 想要更好的中文长篇质量：14B 的 Q4（约 8.9GB）需要部分 offload 到内存，速度会掉到 5–8 tok/s，本机内存只剩 2GB 空闲，不建议

## 七、常见问题

**Q：启动后浏览器打开是空白 / 连不上？**
A：先看模型窗口有没有 `listening on 5001`，再看 8000 窗口有没有报错。手动访问 <http://127.0.0.1:5001/api/v1/model>，返回 `{"result": "koboldcpp/..."}` 说明模型服务正常。

**Q：SillyTavern 里显示 "no connection"？**
A：API 选 Text Completion → KoboldCpp → URL 填 `http://127.0.0.1:5001` → Connect。本机已验证 CORS 通得过，连不上就是 5001 没起来。

**Q：写出来的人物代词乱了（女写成「他」）？**
A：7B 小模型的通病。在每次给方向时明确写「林晚是女性，用『她』」。

**Q：会不会偷偷联网 / 上传内容？**
A：不会。KoboldCpp 只监听 `127.0.0.1:5001`，SillyTavern 只监听 `127.0.0.1:8000`，都是本机回环地址，外网进不来、内容也不出去。

**Q：怎么导出小说？**
A：聊天右上角菜单 → Export → 导出为 txt / md，或者复制到 `output\` 里自己整理。
